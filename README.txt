NIYUUU UNIVERSE — WEBSITE FILES

UPLOAD
- Upload all files and folders in this directory to the ROOT of your GitHub repository.
- Keep index.html and bmw-m4-dream.png together.

ADD YOUR SONG
1. Choose an MP3 audio file that you have permission to use.
2. Rename it exactly: song.mp3
3. Put song.mp3 in the same root folder as index.html.
4. Upload song.mp3 to GitHub and commit the change.
5. Open the website and tap “Play our song”. Mobile browsers require a tap before audio can start.

KITKAT BLAST
The KitKat Blast button creates a burst of animated chocolate pieces.

PHOTOS
The photo pickers preview photos only on the device where they are selected. To show shared photos to visitors, place image files in a photos folder and add them to the HTML.

GITHUB PAGES
Repository Settings > Pages > Deploy from a branch > main > /(root) > Save.
