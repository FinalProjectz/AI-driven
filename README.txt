HER LITTLE UNIVERSE — FOR NIYUUU ♡

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or another browser.

HOW TO ADD YOUR PHOTOS PERMANENTLY
The photo frames currently let you preview images selected on that device only. For the photos to appear for anyone opening the public QR-code link:
1. Put your chosen image files in the photos folder.
2. Edit the photo gallery in index.html and replace each photo frame with an image tag such as:
   <img src="photos/our-photo-1.jpg" alt="Our memory">
3. Upload index.html and the photos folder together when publishing.

HOW TO PUBLISH FREE WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository.
2. Upload index.html and the photos folder (if used) to the repository's main/root folder.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to provide your public website URL.
7. Open that URL on your phone to test it, then make a QR code from the URL and hide it in the teddy bear.

NOTES
- This is a static website; it does not collect or send personal information.
- The Music button makes a simple soft tone using the browser; it is not a recorded song.
- Google Fonts require an internet connection. The rest of the page works locally.
- The BMW scene includes a generated BMW M4 Competition visual (bmw-m4-dream.png). Tap “Start the headlights” to reveal the headlights with a glow animation. Keep this image file beside index.html when uploading the website.
